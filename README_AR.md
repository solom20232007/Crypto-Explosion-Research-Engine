# Crypto Explosion Research Engine (نسخة تأسيسية)

محرك بحث مستقل لدراسة الانفجارات السعرية في العملات الرقمية وبناء نماذج اختبارية. **لا يرسل إشارات تداول ولا ينفذ صفقات**، ولا يتصل ببرامج V4/V5/V6/V7 في هذه المرحلة.

## ما الذي تفعله هذه النسخة؟
- تنزيل شموع Binance Spot التاريخية من أرشيف Binance Public Data.
- تخزين الشموع محليًا في CSV مع إمكانية استكمال التشغيل.
- حساب مجموعة أولية من المؤشرات الفنية والخصائص السابقة للحركة.
- اكتشاف الارتفاعات التاريخية التي تجاوزت 15% خلال 24 ساعة.
- بناء مجموعة بيانات لتوقع ما إذا كان أعلى سعر خلال الـ24 ساعة التالية سيصل إلى +15% من سعر الإغلاق الحالي.
- تدريب نموذج baseline واختباره زمنيًا، وإخراج المقاييس والملفات التي ستتطور لاحقًا.
- حفظ تقارير JSON/CSV محليًا.

## تنبيه مهم عن نطاق البيانات
الإعداد الافتراضي يبدأ من `2023-10-01` وحتى تاريخ التشغيل. تنزيل جميع الأزواج على مدى 3 سنوات قد يكون كبيرًا جدًا؛ لذلك ابدأ بعدد محدود من الأزواج للتحقق من سلامة المسار، ثم وسّع النطاق تدريجيًا.
هذه النسخة تستخدم قائمة الأزواج المتداولة حاليًا من Binance، لذلك لا تشمل تلقائيًا العملات التي أزيلت من التداول تاريخيًا. سنحتاج إضافة سجل تاريخي للأزواج المحذوفة في مرحلة لاحقة لتقليل انحياز البقاء.

## المتطلبات
Python 3.10 أو أحدث.

```bash
python -m venv .venv
# Windows:
.venv\Scripts\activate
# Linux/macOS:
source .venv/bin/activate
pip install -r requirements.txt
```

## بداية سريعة على Windows
```bash
python main.py universe
python main.py collect --symbols BTCUSDT ETHUSDT SOLUSDT --interval 1h --start 2023-10-01 --end 2026-10-27
python main.py analyze --symbols BTCUSDT ETHUSDT SOLUSDT
python main.py train
```

## أوامر البرنامج
- `universe`: يحفظ قائمة أزواج USDT الفورية النشطة إلى `data/universe.csv`.
- `collect`: ينزل الشموع الشهرية من أرشيف Binance. كل ملف يُحفظ فورًا لتسهيل الاستكمال.
- `analyze`: ينتج `reports/explosions.csv` و`data/features.csv` من الشموع المتوفرة.
- `train`: يدرب نموذجًا أوليًا ويكتب `reports/model_metrics.json` ويحفظ النموذج في `models/`.

## تعريفات النسخة الأولى
- **الانفجار التاريخي:** عائد الإغلاق خلال 24 شمعة ساعة متتالية يبلغ 15% أو أكثر.
- **هدف النموذج الأولي:** هل يصل أعلى سعر خلال 24 ساعة تالية إلى 15% أو أكثر مقارنة بالإغلاق الحالي؟
- المؤشرات الأولية: عوائد 1/3/6/12/24 ساعة، RSI-14، MACD، ATR-14، نطاقات Bollinger، متوسطات حجم التداول، تغير الحجم، وتقلب العوائد.
- التقسيم زمني وليس عشوائيًا لمنع تسرب المستقبل إلى التدريب.
- هذا نموذج بحث أولي وليس توصية استثمارية، ولا يُفترض أن تكون نتائجه مربحة قبل اختبارات مستقلة أكثر صرامة.

## بنية المجلدات
- `data/raw/`: الشموع الخام
- `data/`: قوائم الأزواج وملفات الخصائص
- `reports/`: تقارير التحليل والاختبار
- `models/`: النماذج المحفوظة
- `src/`: وحدات التنزيل والتحليل والتدريب
- `config.yaml`: الإعدادات الافتراضية

## حدود النسخة الحالية
1. لا يوجد تحليل أخبار بعد؛ سيضاف كمكوّن مستقل بعد تحديد مصدر أرشيفي قانوني ومستقر وتوقيت نشر موثوق.
2. لا يوجد اتصال أو إرسال إشارات إلى V4–V7.
3. لا يُعتبر احتمال النموذج معايرًا أو صالحًا للاستخدام المباشر قبل اختبارات walk-forward وpaper evaluation.
4. بيانات دفتر الأوامر التاريخية والأخبار قد لا تكون متاحة مجانًا أو بنفس التغطية لجميع العملات.
